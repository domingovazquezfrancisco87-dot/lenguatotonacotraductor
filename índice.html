📖 Cómo entender el Totonaco - 3 Raíces

1. Puhmalhkuy = fogón → puh (hecho) + mah (sobre) + lhkuyath (fuego)

2. Kuxlhanchuh = pan → kuh (corazón) + xlhah (suyo) + chuh (tortilla)

3. Puksnankakgakg = pápalo → puks (oloroso) + nahan (va) + kakg (quelite)
